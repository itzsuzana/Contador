# 🔢 Super Contador

Uma aplicação web simples que conta do número inicial ao número final escolhidos pelo usuário, exibindo o resultado em uma interface moderna com efeito *glassmorphism*.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## 📖 Sobre o projeto

O **Super Contador** permite que o usuário informe um número inicial e um número final, e a aplicação exibe todos os números do intervalo, um a um.

## ✨ Funcionalidades

- Entrada de número inicial e número final
- Contagem automática entre os dois valores
- Interface com visual moderno (glassmorphism, gradientes e animações)
- Validação básica de campos vazios

## 🚀 Como usar

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/super-contador.git
   ```
2. Abra o arquivo `index.html` no navegador (não é necessário nenhum servidor ou instalação).
3. Preencha os campos **Número inicial** e **Número Final**.
4. Clique em **Contar Agora!** e veja o resultado.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da página
- **CSS3** — estilização, gradientes, animações e responsividade
- **JavaScript** — lógica de contagem e manipulação do DOM
